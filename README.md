# ΑΑΔΕ – Αναζήτηση Βασικών Στοιχείων Μητρώου

Μικρή, ελαφριά εφαρμογή για Windows που αναζητά τα βασικά στοιχεία μητρώου
μιας επιχείρησης από ΑΦΜ, χρησιμοποιώντας την υπηρεσία web service
`RgWsPublic2` της ΑΑΔΕ (η ίδια υπηρεσία που χρησιμοποιεί η «Αναζήτηση
Βασικών Στοιχείων Μητρώου Επιχειρήσεων»).

Γραμμένη σε Rust με native Win32 controls ([native-windows-gui](https://github.com/gabdube/native-windows-gui)) —
χωρίς Electron, χωρίς browser engine, μόνο το αρχείο `.exe`.

## Λήψη

Κατεβάστε το τελευταίο `.exe` από τη σελίδα
[Releases](../../releases/latest). Δεν χρειάζεται εγκατάσταση ούτε
Visual C++ Redistributable — απλώς τρέξτε το αρχείο.

Συμβατό με Windows 7, 8, 8.1, 10 και 11 (64-bit).

## Λειτουργίες

- Αναζήτηση στοιχείων επιχείρησης με βάση το ΑΦΜ (επωνυμία, ΔΟΥ,
  διεύθυνση, δραστηριότητες ΚΑΔ, κατάσταση ΑΦΜ κ.λπ.)
- Αποθήκευση του Ειδικού Κωδικού / Συνθηματικού της ΑΑΔΕ στη Διαχείριση
  Διαπιστευτηρίων των Windows (Windows Credential Manager) — όχι σε αρχείο
- Εξαγωγή αποτελέσματος σε αρχείο JSON
- Αλλαγή μεγέθους παραθύρου, ελάχιστο μέγεθος, μεγιστοποίηση

## Προαπαιτούμενα για χρήση

Χρειάζεστε **Ειδικό Κωδικό** (username) και **Συνθηματικό** (password) για
web services, διαφορετικά από τους κωδικούς TAXISnet. Δημιουργούνται από
τη σελίδα της ΑΑΔΕ **«Διαχείριση Ειδικών Κωδικών»**, και η εφαρμογή πρέπει
να είναι εγγεγραμμένη στην υπηρεσία **«Αναζήτηση Βασικών Στοιχείων
Μητρώου»**.

Κανόνες μορφής:
- Κωδικός Εισόδου: μόνο **κεφαλαία** λατινικά Α-Ζ, ψηφία 0-9 και παύλα `-`·
  τουλάχιστον 10 χαρακτήρες, με τουλάχιστον ένα γράμμα και έναν αριθμό.
- Συνθηματικό: λατινικά (κεφαλαία/πεζά), ψηφία και τα σύμβολα
  `!@#$^*()/+=|?;:.,-~{}`· τουλάχιστον 10 χαρακτήρες.

## Build από τον κώδικα

```bash
git clone https://github.com/tedlaz/aade-afm.git
cd aade-afm
rustup toolchain install nightly --component rust-src
cargo +nightly build --release -Z build-std=std,panic_abort --target x86_64-win7-windows-msvc
```

Το έτοιμο `.exe` βρίσκεται στο
`target\x86_64-win7-windows-msvc\release\aade-afm.exe`, ή τρέξτε απλά:

```bash
.\build-win7.ps1
```

Για γρήγορο build/test σε 64-bit Windows 10/11 χωρίς το nightly toolchain
και το ειδικό target, αρκεί το συνηθισμένο `cargo build --release`.
